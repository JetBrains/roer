Ask in plain words

Describe the panel you want. The agent drafts it and Roer opens it next to the terminal while the work keeps going.

Trusted by design

Panels are assembled from a fixed set of Roer components: text, checkboxes, buttons, rows. The agent never ships markup or scripts.

Keep the good ones

Save a panel with the project and reopen it next time, so a one-off dashboard can become part of how the repo works.

Generative UI

Ask for a dashboard. Get one.

“Put CI, deploys and test health on one screen.” The agent gathers the numbers and Roer lays them out beside the session: stat tiles, run cards with live progress, and buttons that report back to the agent when you click them.

Tiles, status cards, work-item boards and full diffs, all from Roer’s own component catalog.

Open a session in your browser

Pick Open This Session in a Browser… and the same session runs in a Chrome tab, terminal and panels included. Or run roer-server on its own, from a container.

Boards and personal tasks

Tell the agent to note something and it lands in the project’s task store (roer task). Boards draw your tasks next to GitHub, YouTrack or Jira issues, in the same lanes.

Speaks A2UI v1.0

Panels follow the open A2UI v1.0 message format, so any agent that can call an MCP tool can draw them.

Review

Read every change before it ships.

The agent works on a branch. Roer shows you that branch as a reviewer would see it, one commit at a time.

Then open the pull request. Same window.

The Pull Request tab uses your own GitHub login. Review comments go straight back into the running session.

  1. DraftClaude writes the title and description.
  2. PushRoer pushes the branch and opens the PR.
  3. ReviewRequest a Copilot review. Roer waits for it.
  4. FixPick threads and hit Fix with Claude.

Session teleport

Leave the terminal. Keep the session.

Start in any terminal with roer shell. Press M-h and the live session moves into Roer, mid-thought. Same process, same scrollback, nothing restarts. Press it again to take it back.

Works for anything that runs in a terminal: Claude Code, vim, a dev server.

Install

Up and running in four steps.

Roer {{release.version}} · released {{release.date}}. The builds are unsigned while Roer is in preview.

  1. Download the app. One universal build for Apple silicon and Intel, macOS 15 or later.

    {{dl.mac.appName}}

  2. Drag Roer to Applications, then clear the quarantine flag. Without it, macOS stops the app on first launch.

    xattr -dr com.apple.quarantine /Applications/Roer.app

  3. Open Roer once. It puts roer on your PATH, so a new terminal can start a session.

    roer shell

  1. Get the .deb, .rpm or .AppImage and the Linux CLI tarball.

    {{dl.linux.label}}

  2. Install the .deb or .rpm. It pulls in tmux for you. Using the AppImage? Install tmux yourself.

  3. Unpack the CLI, put roer on your PATH, and start a session.

    roer shell

Shortcuts use CtrlShift in place of ⌘, leaving plain Ctrl keys to the terminal.

  1. Run Roer_<version>_x64-setup.exe. It installs the app and roer together and adds it to your PATH. SmartScreen will warn, because preview builds are unsigned.

    {{dl.win.label}}

  2. Open a new PowerShell window and start a session. No WSL needed.

    roer shell

Session titles are not shown on Windows yet.
